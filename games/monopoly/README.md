# 地产大亨 · City Ledger

经典 Monopoly 地产经营机制的非官方单骰改编。每回合只投一颗骰子、只掷一次，6 点不续掷。40 格地图、28 块产权，支持单人对策略 AI、2–6 人同屏和 1–6 人好友房（总席位 2–6，空位 AI 补齐）。所有资金均为游戏内虚拟资源。

启动根项目后打开 `/games/monopoly/index.html` 或 `/games/monopoly/online.html`。本地模式自动存档，好友房保存身份并支持刷新恢复。新一局会替换该浏览器的本地存档。

全部金额采用原版本的 **10 倍币值**：起始资金 15000、起点收入 2000、出狱费 500。地价、建筑费、租金、卡牌收支、AI 储备与估价同步换算，最小金额单位为 10。抵押利率仍为 10%，按 10 为单位向上取整以保持原来的实际收费比例。

schema 1 旧局在恢复时自动一次性转换至 schema 2：现金、待付债务、竞拍价、交易报价和结算队列一起转换，位置、建筑等级、骰子与牌序不变。原日志保留在 `legacyEvents`，界面从币值转换记录开始显示，避免旧金额与新金额混杂。旧版联机页面必须刷新后才能继续行动。

当前游戏存档为 schema 5。schema 4 升级时保留资金、位置及已建房屋，新建设按落地规则校验。schema 3 升级时取消未完成的竞拍及后续竞拍队列，未成交的出价不扣款，地产保持无主；已经结算的交易保持不变。恢复 schema 1 / 2 时会继续升级为单骰规则，保留已结算的移动、资金和地产；取消旧双数产生的待续掷机会。旧记录中的两颗骰子属于升级前的历史。掷骰使用约 1.1 秒的六面立体旋转动画，期间锁定游戏操作；最终点数、移动、收支和落点操作统一在动画结束后显示。开启减少动态效果时改为短暂淡入，仍防止重复操作。

## 已实现

地图按窗口可用宽高自动调整比例，始终在棋盘容器内完整显示 40 格，无需内部滚动或切换总览。“定位棋子”直接高亮当前玩家所在地块；窄屏下操作区移至地图下方。40 个地点使用 40 张不同的 3D 棋盘模型风格插画：包括同色地产、四座车站，以及每一处机会和公共基金格。映射以棋盘位置为单位，不按类别复用。产权簿显示选中地块大图，图片清单、内容哈希与生成提示词见 `web/assets/illustrations/ARTWORK.json`。

- 单骰、每回合一次、经过起点收入；6 点不续掷。
- 落地后选择购买或跳过、铁路、公用事业、成套租金与均匀建设。
- 32 房屋与 12 酒店的库存约束、酒店升级与出售、整组清仓。
- 抵押、赎回、交易双方确认、抵押转让费与债务清算。
- 欠玩家和欠银行的不同破产路径，以及连锁继承费用、银行收回地产恢复无主。
- 监狱（6 点出狱）、保留的出狱卡、各 16 张机会和公共基金事件。
- 基于公开资产的规则 AI：购地或跳过、凑套报价、建设和筹款。
- 服务端权威行动、revision CAS、请求去重、隐藏牌序、离席 AI 接管。

## 规则差异

本作以 Hasbro C1009 的机制为参考，完整差异也在游戏内“玩法”显示：

- 单骰玩法：一回合只生成一次 1–6 点结果，公用事业复用该点数计租；取消双数续掷和三连双数入狱。在监狱中掷出 6 点可出狱，三次未成功则付 500 后按最后一次点数移动。

- 固定第一席先手、自动收租；建房或升级酒店仅限本回合移动结算后所在的自有地产，仍要求完整色组、均匀建设、现金与库存充足。其他资产管理保留原有阶段。
- 落地购地：只有到达无主地产的玩家可以按标价购买；不买则保持无主，其他人不能抢购。本版不设拍卖。
- 建筑按库存先到先得；单独降级酒店需四间房，缺货可整色组清仓。
- 每回合最多两次交易提案；首版不支持出狱卡单独交易。抵押转让保持抵押，接收者先付 10%，赎回另付本金加 10%。
- 中文地名与事件描述原创，事件效果固定在 `web/data.js`，不是特定盒装的逐卡复制。
- 标准破产淘汰，不含限时计分、股票、角色技能、免费停车奖池和玩家借款。

## 联机与持久化

Node API：`/api/monopoly`；单实例文件存储：私有数据目录的 `monopoly-rooms.json`。房间 TTL 为 24 小时，每次行动窗口 60 秒；AI 约 0.9 秒一步。超时真人由 AI 代行，但交易报价超时会拒绝。请求轮询推动超时，无独立常驻调度器。未开始的空座可加入，开始后仅原身份恢复。

未来牌序与结算队列不发送到客户端，身份 token 仅保存在对应浏览器，服务端存摘要。退出后不能用旧身份恢复，但其他真人继续游戏；刷新不会主动退出。同源多个标签共享一个玩家身份，真正的另一席需另一个浏览器配置或设备。

Worker 路由已接入，需应用 `deploy/cloudflare/migrations/0008_monopoly_rooms.sql`。代码和本地 SQL 适配测试不代表已经发布到公网。
